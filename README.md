# ShiftFlow — 居酒屋向け月次シフト管理ツール

サーバー不要・HTMLファイル1枚で動く、小規模店舗（居酒屋想定）向けのシフト管理ツールです。
ブラウザで `index.html` を開くだけで使えます。データは端末内（localStorage）に保存されます。

## 主な機能

- **月次シフト表**：セルをタップしてシフト種別を切り替え。今日ハイライト・土日色分け・印刷対応
- **深夜営業対応**：終了時刻を開始より早くすると「翌日またぎ」として計算（例 18:00〜02:00 → 8時間、表示は「18〜翌2」）
- **深夜割増の概算**：22時〜翌5時の勤務を深夜時間として自動集計し、割増率（既定25%）込みの給与概算を表示・CSV出力
- **人員チェック**：時間帯ごと（仕込み／ディナー／深夜など自由に設定）の最低人数を監視し、不足日を警告。平日と土日で別の下限も設定可能
- **シフト自動生成**：スタッフの希望条件（希望休・有給・希望勤務）をロックした上で、月上限・週上限・均等配分を考慮して残りを自動で埋める
- **希望条件入力**：スタッフ本人がログインして翌月の希望を入力できる
- **月次集計**：勤務時間・出勤日数・深夜時間・有給・人件費（管理者のみ）・CSV出力
- **スタッフ管理**：雇用形態・時給・月/週上限・有給残・カラーなど
- **バックアップ**：JSONで書き出し／復元（端末間のデータ移行に使用）
- **スマホ対応**：ボトムナビ＋ドロワーのモバイルUI

## ログインとセキュリティ

- 起動時は必ず**ログイン画面**（管理者 or スタッフ + PIN）
- 管理者の初期PINは `0000`。**初回ログイン後、設定画面から必ず変更してください**
- スタッフの初期PINは「スタッフNo.を4回」（例：No.2 → `2222`）。本人が「PIN変更」から変更できます
- PINは**SHA-256ハッシュ＋ソルト**で保存され、平文では保存されません（管理者もスタッフの変更後PINは閲覧不可。忘れた場合は管理者が初期化）
- PIN入力を**5回連続で失敗すると30秒ロック**
- 無操作が続くと**自動ロック**（既定20分・設定で変更/無効化可能）
- スタッフ権限では、給与・時給の閲覧、シフトの直接編集、設定・スタッフ管理・バックアップ操作はできません
- 表示名などの入力値はHTMLエスケープ済み（XSS対策）

### セキュリティ上の注意（重要）

本ツールは**完全クライアントサイド**で動作します。PIN認証・権限制御は「店舗の共用タブレットで気軽に使う」ことを想定した抑止レベルの保護であり、ブラウザの開発者ツールを使える人からデータを守るものではありません。厳密なアクセス制御や複数端末でのリアルタイム共有が必要な場合は、サーバー側認証を持つシステムをご検討ください。

- データは**端末ごと**に保存されます（端末間で自動同期しません）。端末をまたぐ場合はバックアップ出力→復元を使ってください
- ブラウザのデータ消去（履歴削除等）でデータが消えるため、**定期的なバックアップ出力を推奨**します

## 使い方

1. `index.html` をブラウザで開く（Chrome / Safari / Edge 推奨）
2. 管理者PIN `0000` でログイン → 設定からPINを変更
3. 設定 → 「店舗情報」で店舗名・デフォルト時給・深夜割増率などを設定
4. 設定 → 「シフト種別」で自店の勤務パターンに合わせて編集（初期値：仕込み／早番／遅番／ラスト／フル）
5. 設定 → 「自動生成」で時間帯ごとの最低人数を設定
6. スタッフ管理でスタッフを登録
7. 「希望条件入力」で確定させたい日を先に入力 → 「自動生成」で残りを自動作成
8. 印刷 or CSVで共有

## GitHub Pages での公開

リポジトリの Settings → Pages → Branch: `main` / root を選ぶと、`https://<ユーザー名>.github.io/<リポジトリ名>/` でアクセスできます。
公開する場合も、シフトデータ自体は閲覧者それぞれの端末内にのみ保存されます（リポジトリにデータは含まれません）。

## 技術メモ

- 依存ライブラリなし（Google Fonts のみ外部読み込み）
- PINハッシュ：Web Crypto API（SHA-256）。非セキュアコンテキストでは簡易ハッシュにフォールバック
- 時間計算は「営業日」基準：終了 ≦ 開始 の場合に +24h して翌日またぎとして扱う
- 保存キー：`localStorage["shiftflow_v2_local_state"]`（v2互換。旧バージョンの平文PINは初回起動時にハッシュへ自動移行）
